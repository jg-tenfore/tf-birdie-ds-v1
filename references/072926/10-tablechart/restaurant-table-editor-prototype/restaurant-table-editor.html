Restaurant table layout editor — prototype

Three rooms: bigroom and Patio have saved layouts. Lounge is blank — drag from the palette to set it up. Tap the room name in the bottom bar to switch rooms. Each room saves independently; unsaved changes are flagged with an orange dot.

Tips · Shift+drag a corner handle to temporarily lock aspect ratio · Toggle the lock from the top selection toolbar to make it permanent · Press Delete to remove the selected element
